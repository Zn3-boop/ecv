# AI Desktop Agent 项目路线图

## 当前阶段
- 已完成 monorepo 根目录初始化
- 已跑通 Electron + React + FastAPI 基础链路
- 已接入系统监控、语音指令、自动处置闭环
- 当前正进入“Agent 驱动自动化增强”阶段

## 已完成里程碑
1. FastAPI 健康检查、聊天、语音、自动处置接口已建立
2. Electron 主进程已能采集系统监控并通过 IPC 提供给 React
3. React 已支持监控看板、语音输入、TTS 播报、自动处置时间线
4. `/voice/command` 与 `/automation/handle-alert` 已支持注入实时 system_context
5. LLM 工作流已支持 generator + reviewer 闭环，以及环境变量驱动的真实模型调用

## 本轮新增里程碑
1. 新增 SQLite 本地存储层与自动初始化逻辑
2. 新增 `/storage/*` 接口，覆盖会话记录、消息记录、快捷指令、收藏管理
3. `/chat/agent` 已支持 `conversation_id` 与 `role_prompt`，具备轻量上下文记忆与角色设定注入能力
4. 已补充交付差距分析文档，可用于继续按优先级推进剩余模块

## 当前推荐下一步
1. 在 React 桌面端接入会话侧边栏、快捷指令面板、收藏管理 UI
2. 补 Electron 托盘、窗口置顶、迷你模式、开机自启 ✅ 已完成
3. 接入真实麦克风采集与浏览器端 STT，替换"文本模拟语音输入"
4. 为自动处置增加"确认执行 / 仅建议 / 自动执行"三级策略
5. 增加桌面控制动作白名单，例如打开日志目录、拉起诊断脚本、清理缓存
6. 在前端增加 LLM 状态提示、调用耗时、失败重试与回退标记
7. 补充 Stripe / 登录 / 订阅体系，为出海版本做商业化准备
